## 二、初始化步骤（从零复现）

一键：

    powershell -ExecutionPolicy Bypass -File .\scripts\init-all.ps1

手工（若脚本失败）：

1. 建库：CREATE DATABASE ocms_ruoyi_starter CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci
2. 导入 SQL（顺序固定）：
   - RuoYi-Vue-springboot3/sql/ry_20260417.sql
   - RuoYi-Vue-springboot3/sql/quartz.sql
   - materials/sql/clinic.sql
   - materials/sql/clinic_enterprise_seed.sql
   - materials/sql/clinic_stage3_seed.sql
3. 编译后端：cd RuoYi-Vue-springboot3 && mvn -pl ruoyi-admin -am package -DskipTests
4. 前端依赖：cd RuoYi-Vue3-master && npm install
5. Python venv：cd agent-template && python -m venv .venv && .venv\Scripts\python.exe -m pip install -r requirements.txt
6. 构建知识库：.venv\Scripts\python.exe scripts\build_kb.py

## 三、一键启动

    powershell -ExecutionPolicy Bypass -File .\scripts\start-all.ps1

依次启动：若依后端 -> Python Agent -> 前端，全部就绪后自动打开浏览器。

## 七、常见故障排查

|---|---|
| 后端 8087 起不来 | ruoyi-admin/target/run.log 最后 30 行 |

| 中文乱码 | 客户端加 --default-character-set=utf8mb4 |
| 端口被占 | Get-NetTCPConnection -LocalPort 8087 查 PID |
